Bench setup: the AD3 in place of the TV
Not yet proven on this board: that the DIR9001 locks to the AD3's signal. The generator itself passes its self-test.

  1. Move and power

    Put the board on the bench and power it from the bench supply: 9 V, current limit 0.5 A. On the DIR9001 module (the green board stacked on top, marked "LHY AUDIO DIR9001-I2S"), flip the toggle switch to the coax input.

  2. Make the cable

    Take a spare RCA cable and cut one end off. Inside are a centre conductor and a shield. The RCA plug at the other end goes into the red RCA jack on the DIR9001 module.

  3. Three resistors, wired at the cut end

    All three are from home stock. Wire them like this:

    This turns the AD3's 3.3 V into about 0.4 to 0.8 V, the normal level for coax S/PDIF.

  4. Other AD3 connections

    • DIO 0 stays on the board's serial pin J2 TX. This is optional, it is for the console.
    • Scope probes set to 10x. Probe 1 on BCK at the front DAC socket. Probe 2 on that DAC's data pin. Ground clips on the DAC's ground.

    The probe positions change from test to test. These are the ones for the first test.

  5. Start the generator

    Run these from the repo folder:

    python3 tools/spdif_gen.py selftest
python3 tools/spdif_gen.py run 1017 1526 -12

    selftest needs no wiring. It checks the AD3 pattern by reading it back. run 1017 1526 -12 plays 1017 Hz on the left, 1526 Hz on the right, at -12 dBFS. Ctrl-C stops it.

    A negative right frequency, for example run 1017 -1017 -12, sends the same tone inverted on the right. That is pure surround for the matrix decoder.

    Only one program can use the AD3 at a time. Before starting the generator, press "Release AD3" on the bench page (http://127.0.0.1:8791/). Do not run scope measurements there while the generator runs.

  6. What you should see on this page

    • Digital input: "LOCKED, 48 kHz PCM" with about 48,828 Hz. The AD3's rate is 1.7 % above 48,000, which is fine.
    • The L and R meters at about -12 dB.
    • With the two different tones, the S meter is active.

    If it stays on "NO INPUT SIGNAL", check that the toggle is on coax, that the centre and shield are not swapped, and that the generator is running.

  7. What this setup can and cannot test

    Can:

    • Clicks and data-line disturbance, with the scope.
    • Long soak tests.
    • Distortion and noise of each output.
    • The stereo matrix decoder.

    Cannot:

    • Dolby Digital. One Dolby frame needs 1,536 audio frames and the AD3 pattern memory holds 256. That stays tested with the TV and with tools/dolby_test.sh on the PC.
